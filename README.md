# GPE

A personal collection of programming practice solutions for **NYCU GPE**.

Most files are **standalone solutions** (mainly C++), named after the problem title.  
They are intended for **practice / review** (**UVa-style** stdin/stdout problems).


## Naming

- **`(+)` prefix**: Important / tricky problems — worth extra attention, harder to understand, sometimes requires memorization.
- **No `(+)`**: Regular practice problems.


## Notes

- This repo mainly targets **UVa Online Judge**-style problems (also compatible with other OJs like **ZeroJudge**): read from **stdin** and write to **stdout**.
